申报人：王正。开源许可：Apache-2.0。

开发版本：`0.1.0-dev.15`。材料日期：2026 年 10 月 31 日。

项目仓库：[q0w1ertyuiop/SenWeave](https://github.com/q0w1ertyuiop/SenWeave)。

## 项目目标与价值

SenML 是物联网测量数据的标准表示。记录可共享设备名称、单位、时间和基准数值，应用在拆分、筛选或存储前需要应用这些上下文。通用 JSON／CBOR 编解码库不直接完成这层语义处理。SenWeave 拟为 MoonBit 网关、采集服务和数据工具提供统一的 SenML 解析、校验、展开与交换接口，使不同应用能够复用同一套标准实现。

## 拟实现功能

1. **完整测量语义。** 围绕 RFC 8428 覆盖全部基础字段、数值／文本／布尔／二进制类型、字段约束、上下文继承、相对时间及独立记录输出，并按条款建立测试与实现对应关系。
2. **多格式解析与转换。** 以共享数据模型连接 JSON、CBOR、XML 和 EXI 表示。持续补齐现有 JSON／CBOR／XML 接入覆盖，并建设 EXI 适配；EXI 的依赖、schema、模式及后端方案在开发前期完成验证，各格式分别记录实际完成状态。
3. **版本与扩展。** 增加 RFC 9100 的特征识别、单位注册信息，以及 RFC 9193 的内容格式字段与继承处理；已知扩展、未知可忽略扩展和强制理解扩展采用明确政策。SenSML 流式模式单独设计增量接口与验收，不与有限包入口混用。
4. **可配置的工程接口。** 提供解析、校验、展开、筛选和编码 API，保留输入、深度和输出预算与错误位置；文件、网络和数据库由宿主应用选择。CoAP 收发及存储示例用于展示接入方式。
5. **跨语言验证与公开分发。** 固定 Go／Python 对照版本，使用共同样本分别核对解析、校验、展开与编码结果，记录差异及标准依据；发布 Mooncakes 包并从独立项目安装验证，同步提供 Node.js SDK 与使用文档。

## 已有基础与实施安排

| 参考实现 | 格式范围 | 主要能力 |
| --- | --- | --- |
| SenWeave 当前版本 | JSON／CBOR／XML | 语义展开、预算与诊断；三个 MoonBit 后端已有测试 |
| Go absmach/senml | JSON／CBOR／XML | 提供校验、归一化与编解码接口 |
| Python KPN SenML | JSON／CBOR | 提供基字段处理和单位信息；已有指定版本交换验证 |

已固定 Go 提交和 Python 发布版本，运行 47 组、110 项共同样本，分别核对解码校验、展开与编码，保留实际输出及差异依据。Python 的值更新接口按其实际范围单独记录。项目目标是为 MoonBit 形成可直接调用和安装的完整实现。

当前版本已实现受限范围的 JSON／CBOR／XML 解析、基字段展开、独立输出、SDK、CLI 和 CoAP 示例。既有测试在 native、JS、wasm-gc 各通过 129 项，Node.js 测试通过 53 项；已完成部分外部交换与本地归档消费验证。EXI、后续版本扩展及注册表正式发布仍需实现，现阶段不将其计入已完成成果。

后续按“规范覆盖与依赖验证—解析缺口修复—跨语言对照—多格式及扩展—公开发布”推进。交付包括可复用库、标准覆盖表、固定版本的互操作脚本、消费示例和安装文档。最终以每项承诺功能的实现、独立验证及安装结果验收。
