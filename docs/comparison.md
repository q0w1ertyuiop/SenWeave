# SenML 参考实现比较

核查日期：2026-10-31。SenWeave 为 `0.1.0-dev.13`。表内区分功能声明、源码核查与已运行对照；未执行的项目不计入互操作结果。

| 维度 | SenWeave | Go absmach/senml | Python KPN SenML 1.0.1 |
| --- | --- | --- | --- |
| 数据模型 | MoonBit 类型化记录、原始数字文本与包上下文 | 已核对公开 Record／Pack 类型 | 已运行指定数值／布尔场景 |
| 表示 | JSON／CBOR；XML／EXI 待实现 | README 与源码提供 JSON／XML／CBOR 入口 | 发布版本提供 JSON／CBOR |
| 校验与展开 | 已有共享字段校验、基字段与时间展开、独立输出 | 已核对 Validate／Normalize 接口；尚未运行对照 | 五条交换流程通过，三项差异有明确记录 |
| 单位 | 当前按字符串处理，注册信息与次级单位待实现 | 单位能力需继续逐项核查 | 上游文档列有单位注册信息；未完成逐项运行核对 |
| 扩展与版本 | 当前 version 10；普通扩展可忽略或按接入策略拒绝 | 版本、扩展与零值行为待共同样本验证 | 固定旧发布版本，不作为更新标准的唯一参照 |

| 复用方式 | MoonBit 公共包、三后端测试、Node.js SDK；注册表发布待完成 | Go 模块 | Python 发布包 |

## 已核查版本与来源

- Go 来源为 [absmach/senml](https://github.com/absmach/senml)，此次核查固定到提交 [40cd806](https://github.com/absmach/senml/tree/40cd806e5f6331135c00bfabaf82f037b0d81354)。功能入口已核对文档与源码，运行对照尚未完成。
- Python 使用已发布的 [kpn-senml 1.0.1](https://pypi.org/project/kpn-senml/1.0.1/)，已运行范围与版本差异见[互操作记录](interoperability.md)。
- [farshidtz/senml/v2](https://github.com/farshidtz/senml) 的文档提供模型、校验、归一化、单位及 JSON／XML／CBOR 编解码，可作为另一 Go 对照候选；尚未运行。

## 下一步共同样本

分别比较解析、校验、展开与编码，避免把纯解码接口与完整展开接口直接比较。输入与参考时刻固定，使用相同字段和值类型；JSON 成员顺序和数值拼写差异分别按结构与数值语义判断。对大整数另核对准确文本与编码，对实际运算核对既定 binary64 规则。

双方不一致时保留最小输入，并依据标准定位。结果分别记录为一致、行为差异、某一实现缺陷或尚未覆盖，不把外部库当作标准裁判，也不根据少量旧版本差异推断其他实现的总体质量。
